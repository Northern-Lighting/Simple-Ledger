# 注意事项
## 设计语言
UI 设计语言严格遵循 Material 3 Expressive（M3 Expressive），包括图标、动画、Components 等，以 M3 Expressive 的官方文档为主：https://m3.material.io/components
动画：如果不是我本人要求，动画时间以及组合方式等均按照官方示例来，达到原生安卓的效果
严格使用 M3 Expressive 现有的资源，不自己写已经存在的资源和动画效果

## 代码与 Debug
代码审核由我来决定，重大更改由我来决定，Agent 不得擅自主张
不得在代码里面添加注释（TODO 除外），每次完成编辑后向我报告新增部分的逻辑、内容
要求可能会复用的组件尽量实现复用，减少冗余的代码
如果不是我要求，请不要启动模拟器调试和实机 USB 调试
每次提交 Git 由我决定

## 项目迁移
本项目由原来的 Flutter 项目迁移而来，主要面向竖屏安卓用户，不需要考虑其他端的交互功能，除非本人额外要求
